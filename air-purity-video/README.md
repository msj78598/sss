# فيديو «نقاوة الهواء» — مشاركة الطالبة ديم مشهور الجميعان

فيديو تعليمي احترافي باللغة العربية عن نقاوة الهواء، مُقدَّم كمشاركة من الطالبة
**ديم مشهور الجميعان** — الصف الثالث المتوسط — **متوسطة الوادي والبحيرات**.

- المدة: نحو 3 دقائق و 21 ثانية، بدقة 1920×1080 (Full HD) و 30 إطاراً/ث.
- تعليق صوتي عربي كامل لجميع المشاهد مع موسيقى خلفية هادئة.
- الملف النهائي: `output/نقاوة-الهواء-ديم-الجميعان.mp4`، وصورة الغلاف: `output/poster.jpg`.

## المشاهد
1. العنوان وبطاقة تعريف الطالبة.
2. تعريف نقاوة الهواء وتركيب الغلاف الجوي (رسم دائري متحرك).
3. أبرز ملوّثات الهواء (PM2.5، CO، NO₂، SO₂، O₃، VOCs).
4. مصادر التلوث الخارجية والداخلية.
5. الأثر على الصحة وأرقام منظمة الصحة العالمية.
6. مؤشر جودة الهواء AQI مع مؤشر متحرك عبر الفئات الست.
7. الحلول ومبادرة السعودية الخضراء.
8. الخاتمة والشكر.

## كيف يُبنى الفيديو
الفيديو مولَّد بالكامل من الكود، فيمكن تعديل أي نص أو لون وإعادة التصيير:

| الملف | الوظيفة |
|---|---|
| `scenes.html` | تصميم المشاهد وحركاتها (HTML/CSS) مع محرّك زمن يُصيّر أي إطار عند زمن محدد |
| `narration.py` | نص التعليق الصوتي المشكَّل وتوليده بصوت عربي محلي (Piper عبر sherpa-onnx) وحساب أزمنة المشاهد |
| `render.py` | التقاط الإطارات من Chromium (Playwright)، ضغط H.264، مزج الصوت، وإخراج MP4 |
| `fonts/` | خطوط Cairo وTajawal (رخصة OFL) |

```bash
pip install -r requirements.txt
python3 narration.py          # يولّد الصوت ويكتب build/timing.json (ينزّل نموذج الصوت أول مرة)
python3 render.py --preview   # لقطات سريعة من كل مشهد للمراجعة في build/preview
python3 render.py             # التصيير الكامل إلى output/
```

يستخدم السكربت متصفح Chromium الخاص بـ Playwright؛ إن كان مثبتاً في مسار مختلف مرّر
`CHROME_PATH=/path/to/chrome`.

## المصادر العلمية المذكورة في الفيديو
- تركيب الهواء: نيتروجين 78%، أكسجين 21%، غازات أخرى نحو 1%.
- منظمة الصحة العالمية: نحو 7 ملايين وفاة مبكرة سنوياً مرتبطة بتلوث الهواء، و99% من سكان العالم يتنفسون هواءً يتجاوز الحدود الإرشادية.
- فئات مؤشر جودة الهواء (AQI) الست من «جيد» (0–50) إلى «خطير» (301+).
- مبادرة السعودية الخضراء: هدف زراعة 10 مليارات شجرة داخل المملكة.
