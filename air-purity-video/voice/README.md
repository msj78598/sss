# ملفات الصوت الخارجية (اختياري)

ضع هنا ملفاً لكل مشهد باسم `s1` إلى `s8` بصيغة wav أو mp3 أو m4a، مثل `s1.mp3`،
ثم شغّل `python3 narration.py && python3 render.py`. أي مشهد لا يوجد له ملف
يُولَّد صوته تلقائياً بالمحرّك المحلي.

نص كل مشهد موجود في `narration.py` (القائمة `SCENES`) ليُقرأ كما هو.
أفضل نتيجة لمشاركة مدرسية: تسجيل الطالبة بصوتها عبر الجوال في مكان هادئ.
